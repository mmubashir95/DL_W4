# PyTorch MLP Training Loop

This project demonstrates a complete, beginner-friendly PyTorch training loop
for a small regression MLP.

## Installation instructions

The `instruction.txt` file is a text guide; it is not installed directly. Read
it with:

```bash
cat instruction.txt
```

Install the library listed in that file with:

```bash
python3 -m pip install torch
```

## Run the example

After PyTorch has been installed, run:

```bash
python3 pytorch_training_loop.py
```
